# Icon Hider

**Icon Hider** — небольшая Windows-утилита для быстрого скрытия и показа иконок рабочего стола. Программа работает в фоне через системный трей и поддерживает глобальную горячую клавишу `Ctrl+Alt+H`.

> Проект создан с использованием **ChatGPT** и **Claude**. AI использовался для разработки, рефакторинга, подготовки интерфейса и документации; итоговая структура проекта и код собраны в этом репозитории.

## Возможности

- 🖥️ **Скрытие иконок рабочего стола** — переключение одним нажатием.
- ⌨️ **Глобальная горячая клавиша `Ctrl+Alt+H`** — работает независимо от активного окна.
- 🔔 **Системный трей** — после закрытия окна программа остаётся запущенной в фоне.
- 🎨 **Тёмный интерфейс** — компактное окно без лишних элементов.
- 🟢 **Индикатор состояния** — сразу видно, отображаются ли иконки рабочего стола.
- 🪟 **Иконка приложения** — используется собственная ICO-иконка в окне и при сборке `.exe`.

## Как это работает

Icon Hider не удаляет файлы и ярлыки с рабочего стола. Программа находит системный элемент Windows, в котором отображаются иконки рабочего стола, и переключает его видимость через WinAPI.

Поэтому при повторном включении все иконки возвращаются в прежнее состояние.

## Требования

- Windows 10 или Windows 11
- Python 3.9 или новее — только для запуска из исходников и сборки
- Зависимости из `requirements.txt`

## Управление

| Действие | Как выполнить |
|---|---|
| Скрыть/показать иконки | Кнопка в приложении |
| Быстро переключить состояние | `Ctrl+Alt+H` |
| Свернуть приложение | Кнопка «Свернуть в трей» или крестик окна |
| Открыть приложение из трея | Двойной клик по значку |
| Переключить иконки из трея | Пункт меню «Скрыть/показать иконки» |
| Полностью завершить программу | Пункт «Выход» в трее |

## Если появляется ModuleNotFoundError

Запускайте приложение из корневой папки проекта командой:

```bash
python run.py
```

`run.py` самостоятельно добавляет папку `src` в путь Python и запускает приложение напрямую, поэтому для обычного запуска проекта не требуется импортировать `icon_hider.__main__`.

Также удаляйте старые файлы `__pycache__` после обновления проекта, если они остались от предыдущей версии.


### Запуск из исходников

Запускайте `run.py` из корня проекта. Лаунчер автоматически подключает локальную папку `src`, поэтому отдельная установка пакета не требуется.
